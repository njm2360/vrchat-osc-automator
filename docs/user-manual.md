## 1. 概要

VRChatOscAutomatorは、VRChatに対してOSCコマンドやキーボード・マウス入力を自動的に送信するツールです。
「スロット」と呼ばれる処理単位を並べてシーケンスを組み、ボタン1つで実行できます。

**主な用途:**

- アバター動作（ジャンプ・走る・スナップターン）の自動実行
- OSC対応デバイスへのカスタムコマンド送信
- キーボード・マウス操作の自動化
- 上記を組み合わせた複合シーケンスの実行

---

## 2. 起動と初期設定

### 2.1 送信先の設定

OSCはUDPで送信されます。VRChatを同一PCで動かしている場合、デフォルト設定（127.0.0.1:9000）で動作します。

1. メニュー → **オプション** → **送信先** を開く
2. 表示されているターゲット行の IP アドレスとポート番号を確認する
3. 変更する場合は各フィールドを直接編集し、**有効** チェックボックスをオンにする
4. **追加** ボタンで複数の送信先を追加できる（異なる PC や VR 機器に同時送信する場合）
5. 不要な送信先は選択して **削除** する

> **VRChat のデフォルト:** 受信ポートは9000。OSC機能はVRChatの設定から有効にしてください。

## 3. プロファイルの管理

プロファイルはシーケンス（スロットの並び）をまとめる単位です。用途ごとにプロファイルを分けて管理できます。

### 3.1 プロファイルの作成

- タブ右端の **+** ボタンをクリックすると新規プロファイルが作成されます

### 3.2 プロファイルの切り替え

- **Ctrl+1〜9** でそれぞれ1〜9番目のプロファイルに切り替えられます
- **Ctrl+0** で10番目のプロファイルに切り替えられます

### 3.3 プロファイル名の変更

- タブヘッダーをダブルクリックするとテキストボックスが表示されます
- 名前を入力して **Enter** キーまたはフォーカスを外すと確定します

### 3.4 プロファイルの削除

- タブヘッダー右端の **×** ボタンをクリックします
- 確認ダイアログが表示されます

## 4. スロットの種類と設定

スロットはシーケンスの1ステップです。プロファイルビュー左側のリストに上から順に並びます。

### 4.1 スロットの追加・操作

| ボタン          | 動作                             |
| --------------- | -------------------------------- |
| **追加**        | 選択行の下に新しいスロットを挿入 |
| **コピー**      | 選択スロットを複製して下に挿入   |
| **削除**        | 選択スロットを削除               |
| **上へ / 下へ** | スロットの順序を入れ替える       |

スロットを選択するとリスト内でパラメーター入力欄が展開されます。

### 4.2 コマンド（プリセット）の選択

各スロットの **コマンド** 列のドロップダウンから種類を選びます。
カテゴリはグループ分けされています。

---

### 4.3 スロット種別リファレンス

#### 待機

| 項目         | 説明                     |
| ------------ | ------------------------ |
| **時間(ms)** | 何もせず待機するミリ秒数 |

コマンド間に間隔を設けたいときに使います。

---

#### ランダム待機

| 項目         | 説明                                   |
| ------------ | -------------------------------------- |
| **最小(ms)** | 待機時間のランダム範囲の下限（ミリ秒） |
| **最大(ms)** | 待機時間のランダム範囲の上限（ミリ秒） |

実行のたびに最小〜最大の範囲でランダムな時間だけ待機します。ループ内での繰り返し操作に自然な間隔を与えたいときに使います。

---

#### 繰り返し開始 / 繰り返し終了

「繰り返し開始」から「繰り返し終了」の間のスロット群をループします。

| 項目             | 説明                                          |
| ---------------- | --------------------------------------------- |
| **繰り返し回数** | 0 = 無限ループ、1 以上 = 指定回数だけ繰り返す |

ループはネストできます（繰り返し開始の中に別の繰り返し開始を置く）。

---

#### ブレークポイント

このスロットに到達すると実行が自動で一時停止します。
デバッグやタイミング確認に使います。パラメーターはありません。

---

#### キー送信

1 つのキーを押す・離す・押して離すアクションを送信します。

| 項目           | 選択肢                                                 |
| -------------- | ------------------------------------------------------ |
| **アクション** | 押す / 離す / 押して離す                               |
| **キー**       | ドロップダウンからキーを選択                           |
| **時間(ms)**   | 押してから離すまでの時間（「押して離す」選択時に有効） |

> **ヒント:** キーを「押す」と「離す」を別スロットに分けると、2スロット間に挟んだ他の操作をキー押下状態で実行できます。

---

#### 文字入力

テキスト文字列をキーボード入力として送信します。

| 項目               | 説明                                |
| ------------------ | ----------------------------------- |
| **テキスト**       | 送信する文字列                      |
| **改行を送信する** | オンにすると末尾に Enter キーを送信 |
| **時間(ms)**       | 文字列送信後の待機時間              |

日本語などのUnicode文字も送信できます。

---

#### マウスボタン

マウスボタンのクリック操作を送信します。

| 項目           | 選択肢                   |
| -------------- | ------------------------ |
| **ボタン**     | 左 / 右 / 中             |
| **アクション** | 押す / 離す / 押して離す |
| **時間(ms)**   | 押してから離すまでの時間 |

---

#### マウスホイール

スクロールホイールの回転を送信します。

| 項目             | 説明                                                         |
| ---------------- | ------------------------------------------------------------ |
| **スクロール量** | 正の値 = 上スクロール、負の値 = 下スクロール（1 = 1 ノッチ） |
| **時間(ms)**     | 送信後の待機時間                                             |

---

#### マウス移動

マウスカーソルを移動させます。

| 項目         | 説明                                                                     |
| ------------ | ------------------------------------------------------------------------ |
| **モード**   | **相対**: 現在位置からの移動量（ピクセル）/ **絶対**: スクリーン上の座標 |
| **X / Y**    | 移動量または目標座標                                                     |
| **時間(ms)** | 送信後の待機時間                                                         |

絶対座標のスクリーン範囲については [セクション 9.2](#92-マウス入力モード) を参照してください。

---

#### VRChat ビルトインプリセット（OSC）

VRChat 向けの定義済みアドレスを使ったスロットです。「前後(軸)」「ジャンプ」など一覧から選択できます。

**Float 型（軸系）の設定:**

| 項目                  | 説明                                            |
| --------------------- | ----------------------------------------------- |
| **スライダー**        | -1.0〜+1.0 の値を設定（0.05 刻み）              |
| **時間(ms)**          | その値を送信し続ける時間                        |
| **完了後に 0 に戻す** | チェックすると時間経過後に 0 を送信してリセット |

**Int 型（アクション系）の設定:**

| 項目                  | 説明                                |
| --------------------- | ----------------------------------- |
| **ON / OFF**          | 1（ON）または 0（OFF）を選択        |
| **時間(ms)**          | 送信し続ける時間                    |
| **完了後に 0 に戻す** | チェックすると時間経過後に 0 を送信 |

> **「完了後に 0 に戻す」について:**
> ジャンプや移動コマンドは 0 に戻さないとボタンが押しっぱなしになります。
> シーケンス途中でエラーが起きた場合でも安全のため、基本的にチェックを入れることを推奨します。

---

#### カスタムOSC

任意のOSCアドレスと値を送信します。

| 項目                  | 説明                                                                           |
| --------------------- | ------------------------------------------------------------------------------ |
| **アドレス**          | OSC アドレス（例: `/avatar/parameters/MyParam`）。`/` から始まる必要があります |
| **型**                | Float / Int / Bool / String                                                    |
| **値**                | 型に応じた入力フィールド                                                       |
| **完了後に 0 に戻す** | Bool は false、String は空文字列にリセット                                     |

アドレスが無効な場合、行の背景が赤くなり実行できません。

**値トランジション（Float / Int のみ）:**

型が Float または Int のとき、固定値送信の代わりに **開始値から終了値へ時間をかけて補間** しながら送信できます。

| 項目               | 説明                                                               |
| ------------------ | ------------------------------------------------------------------ |
| **トランジション** | オンにすると固定値入力が開始値・終了値の入力欄に切り替わる         |
| **開始値**         | 補間の開始時点の値                                                 |
| **終了値**         | 補間の終了時点の値                                                 |
| **時間(ms)**       | 補間にかける時間。この時間をかけて開始値から終了値まで値が変化する |
| **補間モード**     | Linear（線形）/ EaseIn / EaseOut / EaseInOut から選択              |

> トランジション中に停止・一時停止した場合、OSC 値は 0（リセット値）に戻ります。

## 5. シーケンスの実行

### 5.1 実行・停止の操作

| 操作         | 方法                                                     |
| ------------ | -------------------------------------------------------- |
| **開始**     | 画面下部の **開始** ボタン、またはメニュー → 操作 → 開始 |
| **一時停止** | **一時停止/再開** ボタン                                 |
| **再開**     | **一時停止/再開** ボタン（再度クリック）                 |
| **停止**     | **停止** ボタン                                          |

### 5.2 実行中の表示

- 実行中のスロット行の左端に緑の丸が表示されます
- ウィンドウ下部のステータスバーに現在の状態が表示されます

### 5.3 実行できない場合

**開始** ボタンが無効な場合は以下を確認してください。

- 送信先が設定されていて1つ以上の送信先が有効である
- プロファイル内にスロットが1つ以上ある
- 赤くなっているスロット（アドレスエラー）がない

## 6. ループ実行

プロファイルビュー内の **ループ実行** チェックボックスをオンにすると、シーケンス全体を最後まで実行した後に先頭から繰り返します。

シーケンス内の「繰り返し開始/終了」スロットによるループとは独立しています。

---

## 7. グローバルホットキー

アプリがバックグラウンドの状態でも、キーボードショートカットでシーケンスを操作できます。

### 7.1 ホットキーの設定

メニュー → **オプション** → **ホットキー** を開きます。

| ホットキー        | 用途                   |
| ----------------- | ---------------------- |
| **開始**          | シーケンスの開始       |
| **一時停止/再開** | 一時停止と再開のトグル |
| **停止**          | シーケンスの停止       |

---

## 8. キーリピート設定

「キー送信」スロットで **押す** アクションを使った場合に、キーを押し続けている間の自動リピートを設定します。

メニュー → **オプション** → **キーリピート** を開きます。

| 項目                         | 説明                                             |
| ---------------------------- | ------------------------------------------------ |
| **キーリピートを有効にする** | リピート機能のオン/オフ                          |
| **最初のリピートまでの遅延** | 最初のリピートが始まるまでの遅延（ms）。0 = 即時 |
| **リピート間隔**             | スライダーで「○ 回/秒」を設定                    |

---

## 9. 入力モード設定

メニュー → **オプション** → **入力モード** から変更します。

### 9.1 キーボード入力モード

| モード                           | 説明                                 | 推奨 |
| -------------------------------- | ------------------------------------ | ---- |
| **スキャンコード**（デフォルト） | 物理キーボードのスキャンコードで送信 | ◎    |
| **バーチャルキー**               | Windowsの仮想キーコードで送信        |      |

### 9.2 マウス入力モード

| モード                             | 説明                                                 | 推奨 |
| ---------------------------------- | ---------------------------------------------------- | ---- |
| **仮想デスクトップ**（デフォルト） | 全モニターを含む仮想デスクトップ全体を座標空間とする | ◎    |
| **スタンダード**                   | プライマリモニターのみを座標空間とする               |      |

絶対座標で **マウス移動** スロットを使う場合、モードによって同じ X/Y 値が指す位置が異なります。

## 10. エクスポート・インポート

プロファイルをJSON形式でエクスポートし、他の環境にインポートしたり、バックアップとして保存できます。

### 10.1 エクスポート

1. エクスポートしたいプロファイルのタブを選択する
2. **エクスポート** ボタンをクリック
3. ダイアログにJSONテキストが表示される
4. テキストをコピーしてファイルなどに保存する

### 10.2 インポート

1. インポート先のプロファイルのタブを選択する（既存スロットは上書きされます）
2. **インポート** ボタンをクリック
3. JSON テキストを貼り付けてOK
4. 既存スロットがある場合は確認ダイアログが表示される

> **上書き動作:** インポートはスロット全体を置き換えます。プロファイル名もインポートデータの名前で上書きされます。

## 11. トラブルシューティング

### 画面の表示が乱れる・描画関連でクラッシュする場合

GPUドライバとの相性で描画に問題が出る場合は、起動オプション`--software-rendering`を付けることでソフトウェアレンダリングで動作させることができます。

1. `VrcOscAutomator.exe`のショートカットを作成する
2. ショートカットを右クリック →「プロパティ」を開く
3. 「リンク先」の末尾に半角スペースを空けて`--software-rendering`を追記する

   ```text
   C:\...\VrcOscAutomator.exe --software-rendering
   ```

4. 以後このショートカットから起動する
